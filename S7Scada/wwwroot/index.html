TIA Portal 设置
  1. CPU 属性 → 防护与安全 → 勾选"允许 PUT/GET 通信"
  2. DB 属性 → 取消勾选"优化的块访问"并重新编译
  3. 确认 CPU 处于 RUN 模式
Modbus TCP 设置
  1. 确认设备已启用 Modbus TCP 服务并开放端口（默认 502）
  2. 从站号（Unit ID）需与设备组态一致，多数设备为 1
  3. 寄存器按大端字序（高字在前 AB CD）解析
