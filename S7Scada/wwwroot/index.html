TIA Portal 设置
  1. CPU 属性 → 防护与安全 → 勾选"允许 PUT/GET 通信"
  2. DB 属性 → 取消勾选"优化的块访问"并重新编译
  3. 确认 CPU 处于 RUN 模式
Modbus TCP 设置
  1. 确认设备已启用 Modbus TCP 服务并开放端口（默认 502）
  2. 从站号（Unit ID）需与设备组态一致，多数设备为 1
  3. 寄存器按大端字序（高字在前 AB CD）解析
Modbus RTU 设置
  1. RS485 为 A/B 两线半双工；RS232 为 TX/RX/GND，二者均使用下方同一组串口参数
  2. 波特率 / 数据位 / 停止位 / 校验需与从站设备完全一致（默认 9600-8-N-1）
  3. 从站号需与设备地址一致；A/B 接反时通信会失败，可对调后再试
  4. 寄存器地址写法与 Modbus TCP 一致：HR100 / 40001 / CO0
原始 TCP/IP 设置
  1. 用于无标准协议的自定义设备（扫码枪 / 称重仪 / 串口服务器等）
  2. "发送报文"填十六进制，每次扫描前发送一次；留空则只接收设备主动上报的数据
  3. 标签地址填响应数据中的字节偏移（0、4、8…），数据类型在标签里选择
  4. 只取一帧数据：设备停止发送后按空闲超时（IO 超时的 1/5）判定帧结束
